# Genesis Engine · Biome.AI

Интерактивная эволюционная песочница на C#/.NET 8 и Raylib-cs. Интерфейс на русском; обновлённая процедурная пиксельная отрисовка воды, берегов, растительности, камней, жителей, хищников и построек.

## Запуск

Откройте `GenesisEngine.sln` в Visual Studio 2022 17.8+ с .NET 8 SDK, выберите `Genesis.Engine.App` запускаемым проектом и нажмите F5.

```powershell
dotnet build GenesisEngine.sln -c Release
dotnet run --project src/Genesis.Engine.App -c Release
```

Windows: приложение использует установленный системный Segoe UI с явно загруженными кириллическими символами. Шрифт не распространяется вместе с исходниками.

## Инструменты и управление

Выберите кнопку слева, затем нажмите или удерживайте ЛКМ на карте:

- **Наблюдать** — выбрать жителя и просмотреть гены, энергию, возраст, поколение и сложность мозга.
- **Горы / Низины** — поднять или опустить рельеф.
- **Вода / Пустыня** — увлажнить и затопить / высушить и поднять мелководье.
- **Тепло / Холод** — менять температуру в градусах Цельсия.
- **Лес / Пища / Камень** — разместить растительность и ресурсы.
- **Пожар** — поджечь область; огонь расходует топливо, распространяется по соседним клеткам и повреждает жителей.
- **Хищник / Житель** — разместить одно существо на нажатие.
- **Очистить** — удалить существ, ресурсы и постройки в области кисти.

| Действие | Управление |
|---|---|
| Размер кисти | Колесо мыши |
| Масштаб карты | Ctrl + колесо |
| Перемещение карты | Средняя кнопка мыши |

Сохранение: `Saves/world.json` рядом с запущенным приложением. Новый снимок сначала полностью записывается во временный файл на том же диске, затем заменяет предыдущий; это снижает риск потерять старое сохранение при ошибке записи. Сохраняются карта, климат, ресурсы, существа, геномы, полные графы мозга, племена, постройки и отношения. Формат версионирован и проверяется при загрузке. Формат v3 дополнительно хранит оплаченные технологии племён; начиная с v2 сохраняются состояние явного генератора SplitMix64 и летопись. Регрессионный тест сравнивает полные снимки после 300 шагов продолжения с рождениями и размещением жителей. Старые v1 загружаются без гарантии прежнего случайного продолжения. Из-за смены генератора тот же seed создаёт иной мир, чем в ранних версиях. Межплатформенная побитовая идентичность чисел с плавающей точкой не заявляется.

## Что происходит в мире

- Физические и поведенческие гены наследуются с кроссовером и ограниченными мутациями.
- Мозги получают сигналы ресурсов, высоты, энергии и препятствий. Начальная популяция имеет симметричную предрасположенность к поиску пищи; это не обучение с нуля.
- Сети могут наследовать и добавлять скрытые узлы/связи. **NEAT-подобная онлайн-эволюция** группирует мозги по генетической дистанции (совпадающие, непарные и избыточные связи, разница весов), выбирает совместимых партнёров и делит репродуктивный рейтинг на размер вида. Рейтинг учитывает энергию, зрелость и потомство. Это не канонический поколенческий NEAT с отдельной задачей оценки приспособленности; идентификаторы видов пересчитываются при изменении популяции.
- Движение использует постоянное направление и отражение при столкновении с границей. Датчики за пределами мира видят препятствие и отсутствие еды, а не копию крайней клетки.
- Питание, затраты энергии, размножение, старение, температура, пожар и хищники влияют на выживание.
- Социальные жители поблизости формируют племена. Племена собирают ресурсы, оплачивают хижины, фермы, оружие и дорожные маркеры; развитие видно в летописи.
- Фермы производят еду с учётом климата; хижины распределяют запас пищи. Вооружённый охотник защищается от близкого хищника, расходуя энергию, дерево и камень; бесплатной защитной ауры нет.
- Союзные племена прокладывают оплачиваемые дороги между хижинами. По непрерывной безопасной дороге возможен ограниченный обмен пищей, деревом и камнем с сохранением общего количества ресурсов; пожар или разрыв дороги останавливает обмен. Караваны пока не моделируются.
- Переходы между союзом, войной и нейтралитетом фиксируются в летописи. Конфликты остаются упрощёнными потерями энергии рядом с противником, не тактической системой.
- После оплаченных открытий племя может освоить изготовление орудий (экономит камень при охоте), лечение (тратит запасы пищи на одного пострадавшего от пожара или климата) и противопожарные просеки (тратит камень на расчистку горючего у хижины). Это явные правила, не результат изобретений нейросети.

Социальное развитие **основано на явных правилах**, а не на самостоятельном изобретении технологий нейросетью. Дороги строятся платными сегментами между хижиной и фермой по маршруту A*, обходящему воду, высокие горы и огонь. Если пути нет, ресурсы не списываются. Жители пока не используют дороги как обязательные маршруты перемещения. Реалистичная гидрология и физика плавания отсутствуют.

## Исправление поведения у границ

Раньше постоянный выход сети упирался в `Clamp`, а датчик за картой считывал крайнюю клетку: агент продолжал идти в стену. Сейчас исправлены граничные сигналы, устранён общий постоянный сдвиг начальных мозгов, добавлено сохраняемое отражённое направление.

Регрессия на четырёх seed после 60 секунд: во всех случаях живые агенты во всех четырёх квадрантах, доля у самой границы (полоса 1 клетка) проверяется регрессионным тестом и должна оставаться ниже 15%. Это проверка конкретного сценария, не обещание равномерности для любой среды.

## Проверки

```powershell
dotnet test GenesisEngine.sln -c Release
dotnet run --project tools/Verify -c Release
dotnet run --project src/Genesis.Engine.App -c Release -- --smoke
dotnet run --project tools/Benchmark -c Release -- 600 2000 10000
dotnet run --project src/Genesis.Engine.App -c Release -- --benchmark-render
```

Ранее сохранённое измерение (до изменения генератора случайности) — headless-стресс на карте 160×90, fixed-step 1/30, seed 42, 120 измеренных шагов после прогрева. На машине разработки (.NET 8, 8 логических CPU) 600/2000/10000 жителей дали средний шаг примерно 6.47/4.35/18.36 мс; p95 — 11.62/12.08/19.87 мс. На 10 000 максимальный шаг достиг 272 мс, поэтому стабильность ещё требует работы. Это **не FPS окна**: отрисовка отсутствует, GC и системная нагрузка входят в измерение. Социальная классификация может иметь квадратичную стоимость при изменении состава. Для графики теперь есть отдельный `--benchmark-render`: настоящее окно, обычный рендерер и HUD, по одному полному шагу симуляции на каждый кадр, 30 прогревочных и 120 измеренных кадров на популяцию. Учитывается вызов EndDrawing, ограничение FPS снято; данные записываются в `render-benchmark-results.json`. Это стресс-тест с искусственно размещёнными агентами сверх игрового лимита, не гарантия целевой производительности.

Headless-результаты сохраняются в [benchmark-results.json](<benchmark-results.json>). Графические отчёты: исходный [render-baseline.json](<docs/render-baseline.json>) и после кэширования рельефа [render-benchmark-results.json](<render-benchmark-results.json>). На AMD Radeon Vega 8, 1480×940, средний throughput для 600 / 2000 / 10000 жителей вырос с **18.71 / 14.89 / 6.54 FPS** до **71.86 / 60.02 / 24.40 FPS**. Но p95 полного кадра по-прежнему **49.59 / 57.89 / 75.08 мс** — стабильные 60 FPS не достигнуты. Кэш рельефа обновляется раз в 6 тактов, изменения от кисти мгновенные, зелень/пища иногда запаздывают до 5 тактов. Подробности и ограничения методики — [PERFORMANCE.md](<docs/PERFORMANCE.md>).

Вспомогательный Verify выполняет синхронные xUnit Facts напрямую, если VSTest недоступен в окружении. Не поддерживает fixtures, theories и async. Smoke открывает настоящее окно на 120 кадров и сохраняет `genesis-preview.png` в рабочую папку.

## Честные границы текущей версии

Это расширенный прототип, **не полная реализация всех пунктов первоначальной концепции**.

- Игровой лимит популяции 600; текущая симуляция использует обычные списки и однопоточный цикл. Добавлен отдельный проверенный реестр компонентов `EntityRegistry` с плотными хранилищами, поколениями ID и запросами без временных коллекций, **но рабочая симуляция ещё не переведена на него**. Пространственный индекс хищников хранит ссылки на агентов. Headless-стресс на 10 000 синтетических агентов не разрешает игровой лимит и не гарантирует 60 FPS. Arch/HypEcs не подключены.
- Нет канонического поколенческого NEAT: реализован онлайн-вариант с совместимостью видов и разделением репродуктивного рейтинга, без эпох и отдельной fitness-задачи.
- Нет развитого градостроительства, тактических войн, переговорной дипломатии или управляемых нейросетью социальных действий. Торговля — ограниченный обмен по дорогам без караванов и цен.
- Нет музыки, Steam-интеграции, B2B API и плагинов Unity/Unreal.
- Отрисовка процедурная, не набор авторских анимированных pixel-art ассетов.

Ядро не зависит от Raylib. Системы среды, цивилизации, нейроэволюции и сохранения разделены по файлам для дальнейшего развития. В текущем шаге инференс мозга и сенсоры не создают временные массивы после прогрева; headless-бенчмарк вынесен в отдельный проект.
